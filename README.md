# Sireus

Одностраничный сайт на чистом HTML, CSS и JavaScript — без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили (адаптивная вёрстка, тёмная тема)
- `script.js` — меню, анимации, форма

## Публикация

Сайт можно выложить на GitHub Pages: Settings → Pages → выбрать ветку и корневую папку.
