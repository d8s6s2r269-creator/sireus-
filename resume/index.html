# Process · 6 steps

Как я работаю над задачей

Один и тот же путь для лендинга и для приложения. Меняется только глубина каждого шага.

  1. Бриф

    Выясняю цель, аудиторию и ограничения.

  2. Исследование

    Смотрю конкурентов, описываю пользователей.

  3. Структура

    User flow и карта экранов.

  4. Вайрфреймы

    Чёрно-белые макеты, согласование.

  5. UI-дизайн

    Стиль, компоненты, все состояния.

  6. Передача

    Прототип и макеты для разработки.

# Cases · учебные проекты

Кейсы

Учебные и концептуальные проекты. Каждый показывает путь от задачи к решению, а не только финальную картинку. Замените их на свои работы.

Пример · мобильное приложение

Приложение доставки еды: быстрый повторный заказ

Задача
Пользователи часто заказывают одно и то же, но каждый раз проходят весь путь заново.
Что сделал
Опросил 5 знакомых, нарисовал user flow, добавил блок «Повторить заказ» на главный экран.
Результат
Путь до оплаты сократился с 7 шагов до 3 в кликабельном прототипе.
  • Исследование
  • User flow
  • Прототип
Пример · лендинг

Лендинг локальной кофейни

Задача
У кофейни есть только страница в соцсети: не видно меню, адреса и часов работы.
Что сделал
Собрал структуру по вопросам гостей, сделал дизайн для десктопа и телефона, UI-кит из 12 компонентов.
Результат
Вся ключевая информация видна на первом экране телефона.
  • UI
  • Адаптив
  • UI-кит
Пример · редизайн

Редизайн трекера привычек

Задача
В оригинальном приложении трудно понять прогресс за неделю.
Что сделал
Провёл UX-аудит по 10 эвристикам Нильсена, переделал экран статистики и онбординг.
Результат
3 из 4 тестировщиков нашли недельный прогресс меньше чем за 10 секунд.
  • UX-аудит
  • Редизайн
  • Тестирование
